# Embedded CA bundle

`roots.pem` is compiled into the binary (`//go:embed` in [`../ca.go`](../ca.go)) and
used as the TLS trust store for `-mode ws`. Stock modem firmware ships no
`/etc/ssl/certs`, so the relay carries its own roots.

**These are public root CA certificates — not secrets.** They are the same trust
anchors shipped in every browser and OS, published by the CAs themselves. Each
contains only a public key and metadata.

## Why these roots

The default gateway (`opencarwings.viaaq.eu`) is Cloudflare-fronted, and Cloudflare
rotates its edge issuer between **Google Trust Services** and **Let's Encrypt
(ISRG)**. Both families are bundled — plus the **GlobalSign** cross-sign anchor the
GTS chain currently uses — so TLS keeps validating across a rotation without a new
binary.

## Provenance

authoritative publisher and refuses anything that is not self-signed. Each cert in

## Verifying / regenerating

Reproduce the bundle from the authoritative sources and confirm it matches what is
committed — this is exactly what CI does on every change:

```bash
sh tools/mkca.sh
git diff --exit-code ca/roots.pem   # no output = the committed bundle is reproducible
```

Inspect the committed certs directly:

```bash
openssl storeutl -noout -text -certs ca/roots.pem   # or: openssl crl2pkcs7 -nocrl -certfile ca/roots.pem | openssl pkcs7 -print_certs -noout
```
